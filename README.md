# SkyClock

**▶ Open it live: https://friedsalad21.github.io/SkyClock/**

Weather and clock dashboard. Live weather from the free [Open-Meteo](https://open-meteo.com/) API (no key) for your location or any searched city: current conditions, feels-like, wind, humidity, UV, a 24-hour strip and a 7-day forecast, with a °C/°F toggle. A big local clock plus world clocks you can add and remove (saved in your browser). Sunrise and sunset with a sun arc, and the moon phase worked out locally. Dark and light themes, works on a phone.

Single `index.html`, no build step: open it in a browser.
